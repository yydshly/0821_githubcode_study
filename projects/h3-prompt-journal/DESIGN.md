# H3 Prompt Journal 网页研究设计契约

## Design contract

```text
Entry mode: revision-led implementation
Request revision: 13
Target user and context: 想评估、学习或复用 MiniMax H3 提示词方法的内容创作者、提示词工程师和研究者
Desired first impression: 这是一份已经完成阶段性验证的研究档案；读者先看到结论、价值与使用边界，再按需进入六个案例和历史实验台
Visual ambition: Functional + Editorial
Experience architecture: Editorial Flow + Functional Workbench
Visual constraints: 延续总展厅的纸张感与强层级；通过编号、时间轴、参考角色卡和等宽文本表达“研究档案”；完整支持浅色/深色
Information constraints: 必须区分上游事实、作者经验性结论、本研究实测和未来建议；首屏明确“阶段性归档”不等于模板已被证明可直接生产，不宣称网页实际调用 H3
Operation constraints: 纯静态 HTML/CSS/JS；无需登录、后端、API key 或构建步骤；键盘可达
State constraints: 归档状态、六个案例选择态、公共字段与策略字段编辑态、4–15 秒校验态、参考职责编辑态、英文生产版/中文理解版切换态、复制/下载/重置反馈、浅色/深色主题
Environment constraints: GitHub Pages 子路径；桌面、平板、390px 手机；外部视频失败时保留上游链接作为回退
Primary journey: 阅读归档结论 → 判断仓库是否适合当前任务 → 采用“策略原语 + AI 定制改写 + 可观察性检查”的后期用法 → 需要查证时再进入六个真实案例、历史实验台和完整结项文档
User-defined phases: 总结本轮研究；给出后期使用建议；详细说明上游仓库的价值及对后续研究的意义；将 H3 Prompt Journal 研究项阶段性归档；提交并发布到远端 GitHub
Required artifacts: 独立结项归档文档、项目 README 归档入口、总仓库与项目目录状态更新、演示页首屏归档结论与六案例总表、后期使用流程与停止条件、原有六份真实 MP4 与输入图对照完整保留、浏览器验收记录、远端 PR 与 Pages 发布验证
Autonomy authorization: 用户明确要求以网页方式完成分析与演示，可自主进行可逆的页面结构和视觉决策
User-decision boundary: 不调用真实 MiniMax 服务；不添加账号、后端、付费接口；不上传或保存用户素材；不复制整套上游提示词和大型媒体文件
Observable completion criteria: 首屏在进入模板前说明阶段性归档、一次覆盖性测试而非统计基准、CASE 006 为本轮最佳但仍有小偏差；六案例总表清楚区分通过项与主要失败；页面说明模板应作为诊断清单而非直接复制成品，并给出 AI 定制改写、语义冲突检查、任务减量、可观察性校验、外部生成和结果复盘的后期流程；结项文档详细说明上游仓库对提示词工程、研究方法和后续子项目评估框架的价值；总索引状态统一为 archived；原有实验台、双语下载、11 张参考图、六份真实 MP4、输入输出对照和主题切换保持可用；1440、768、390 三个视口无页面级横向溢出；远端 PR 合并且 GitHub Pages 展示归档版
```

## 设计方向

| 决策 | 选择 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 信息层级 | 先给定位与证据边界，再进入交互实验台 | 首屏只保留一个主要行动 | 首次扫描能分辨“案例库”与“生成器” |
| 字体角色 | 衬线大标题 + 无衬线正文 + 等宽实验元数据 | 不依赖字体下载 | 中英文和代码骨架均清晰 |
| 色彩 | 暖纸浅色、墨黑深色，荧光黄绿作为操作强调 | 强调色不承担唯一语义 | 两主题正文、边框、焦点清楚 |
| 材质与深度 | 平面研究卡、细边框、少量黏贴标签感 | 不使用重阴影和装饰性渐变 | 结构优先于装饰 |
| 密度 | 概览简洁，案例细节按选择展开 | 移动端单列，代码区横向可滚动 | 390px 不产生页面级横向溢出 |
| 交互 | 原生按钮、复选框、主题切换、复制 | 有选中、hover、focus、反馈状态 | 键盘可完成核心闭环 |
| 动效 | 只用于状态切换和轻微进入反馈 | `prefers-reduced-motion` 下关闭 | 无动效也不丢失信息 |
