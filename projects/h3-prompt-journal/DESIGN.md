# H3 Prompt Journal 网页研究设计契约

## Design contract

```text
Entry mode: revision-led implementation
Request revision: 12
Target user and context: 想评估、学习或复用 MiniMax H3 提示词方法的内容创作者、提示词工程师和研究者
Desired first impression: 这是一个既能理解六种策略、又能当场产出可用 H3 Prompt 的生产工作台
Visual ambition: Functional + Editorial
Experience architecture: Editorial Flow + Functional Workbench
Visual constraints: 延续总展厅的纸张感与强层级；通过编号、时间轴、参考角色卡和等宽文本表达“研究档案”；完整支持浅色/深色
Information constraints: 必须区分上游事实、作者经验性结论、本研究推断和未来设想；不宣称网页实际调用 H3
Operation constraints: 纯静态 HTML/CSS/JS；无需登录、后端、API key 或构建步骤；键盘可达
State constraints: 六个案例选择态、公共字段与策略字段编辑态、4–15 秒校验态、参考职责编辑态、英文生产版/中文理解版切换态、复制/下载/重置反馈、浅色/深色主题
Environment constraints: GitHub Pages 子路径；桌面、平板、390px 手机；外部视频失败时保留上游链接作为回退
Primary journey: 选择策略模板 → 用中文理解每段含义 → 填写项目与参考图职责 → 调整策略专属参数 → 通过校验 → 切换英文生产版并复制或下载 → 在 H3 中配合参考图使用
User-defined phases: 分析能力；演示能力；说明使用场景；提出可扩展方向；本次 revision 将 CASE 002 双人 3:1 差速视频作为真实失败演示接入，说明画幅预览与实际文件的区别、总结不可观察与切镜原因，并提供不沿用完整模板的 V2 中英双语修复 Prompt
Required artifacts: 项目研究 README、分析文档、中英双版本生产 Prompt 设计器、CASE 001–005 五套真实测试包与 11 张参考图、逐套原生立体声方案、CASE 001–006 六份外部真实 MP4、客观偏差与提示词诊断记录、CASE 001 三身份适用场景与不适用边界、CASE 002 与 CASE 005 的 V2 中英双语修复 Prompt 及原理说明、真实输出区持续可见的输入图与输出视频对照、总索引入口、浏览器验收记录
Autonomy authorization: 用户明确要求以网页方式完成分析与演示，可自主进行可逆的页面结构和视觉决策
User-decision boundary: 不调用真实 MiniMax 服务；不添加账号、后端、付费接口；不上传或保存用户素材；不复制整套上游提示词和大型媒体文件
Observable completion criteria: 六种模板均能切换英文生产版与中文理解版；CASE 001–005 样例 V1 Prompt 与对应模板恢复默认后的输出逐字一致；11 张参考图均可加载和下载；每套明确原生立体声、动作声、音乐或对白关系；CASE 001–006 六份返回 MP4 可播放且音轨存在，页面同时呈现通过项、偏差和不夸大的归因诊断；CASE 002 明确实际文件为正常 16:9、预览模糊边未编码入文件，25 个均匀抽样帧均未显示双脚，约 3.21s 与 9.71s 存在切镜，因而无法验证蝴蝶步与 3:1 比例；CASE 002 V2 不覆盖 V1，标为待验证，并以固定全身双人景别、一个可数动作周期、无切镜和可听脚步组替代近距环绕；CASE 003 的三张姿态输入持续可见，页面如实区分身份与姿态顺序通过、微型飞行语法失败、后段静止和声音空间证据边界，并解释默认模板为何可能弱于目标导向的自由提示词；CASE 004 的三张输入图持续可见，并分别标明身份、装备与摄影职责；CASE 001 结果区明确三身份连续入场的核心价值、四类适用场景及不适用边界；CASE 005 明确节点通过但因果链断裂，并提供不覆盖 V1、标为待验证的 V2 中英双语 Prompt，解释“锁定因果、缩减剧情、分层放权”原理；加入输出视频后输入图仍独立、持续可见，视频封面来自输出成片而非输入图；三个视口不溢出
```

## 设计方向

| 决策 | 选择 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 信息层级 | 先给定位与证据边界，再进入交互实验台 | 首屏只保留一个主要行动 | 首次扫描能分辨“案例库”与“生成器” |
| 字体角色 | 衬线大标题 + 无衬线正文 + 等宽实验元数据 | 不依赖字体下载 | 中英文和代码骨架均清晰 |
| 色彩 | 暖纸浅色、墨黑深色，荧光黄绿作为操作强调 | 强调色不承担唯一语义 | 两主题正文、边框、焦点清楚 |
| 材质与深度 | 平面研究卡、细边框、少量黏贴标签感 | 不使用重阴影和装饰性渐变 | 结构优先于装饰 |
| 密度 | 概览简洁，案例细节按选择展开 | 移动端单列，代码区横向可滚动 | 390px 不产生页面级横向溢出 |
| 交互 | 原生按钮、复选框、主题切换、复制 | 有选中、hover、focus、反馈状态 | 键盘可完成核心闭环 |
| 动效 | 只用于状态切换和轻微进入反馈 | `prefers-reduced-motion` 下关闭 | 无动效也不丢失信息 |
