## CASE 001 三人物遮挡衔接真实输出（revision 7）

### 结果与归因证据

- 返回文件 `video_1787292798992.mp4` 已作为原始 MP4 接入；`ffprobe` 报告 `15.083333s / 1344×768 / H.264 / 24fps / 4,222,424 bytes`。
- 音轨为 `AAC / 32kHz / 2 channels / stereo`，平均响度 `-19.0 dB`、峰值 `-6.3 dB`；以 `-50 dB` 为阈值时没有持续超过 1 秒的静音段。
- 每秒抽帧确认三人的脸、发型与黑色西装 / 钴蓝夹克 / 米白连衣裙可辨认，画廊和光向基本统一，最终完成三人合影。
- `scene > 0.25` 没有发现明显硬切；较低的 `scene > 0.10` 在约 `4.0 / 4.04 / 7.04 / 10.0s` 出现变化。相邻帧检查显示这些变化与人物近身遮挡和多人构图转换对应。
- 偏差为：未来人物在遮挡完成前提前入画；第二、第三人物没有分别完成清楚的独立环绕；人物经过前景的感觉强于严格的遮挡式环绕；多人同框开始过早。
- 归因结论：提示词设计对失败有明显贡献，但模板格式不是单一根因。15 秒内堆叠三次完整环绕、两次交接和最终合影造成任务过载，且缺少站位、单向相机路径、遮挡占画比例及未来人物首次可见时间；模型面对三身份、多参考、单镜头和两次精确遮挡也存在能力方差。
