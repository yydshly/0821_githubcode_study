# H3 CASE 001–005 真实前置信息包

这五套样例用于外部调度 MiniMax H3。本站不调用付费服务，也不把待生成内容冒充成真实成片。

## 统一使用方式

1. 在研究页面的真实输出与待测输入区域选择案例。
2. 下载该案例卡片中的全部 Picture。
3. 下载英文生产版 Prompt；中文版本用于理解和修改。
4. 按卡片中的 `MiniMax-H3 / Ref2VA / 768P / 时长 / 画幅` 参数生成。
5. 确认输出包含可播放的原生立体声音轨，再保存 MP4。

页面样例下载按钮直接从上方设计器的默认状态生成 Prompt，因此“样例 Prompt”和“恢复默认后的模板输出”完全一致。

## 真实输出接入规则

- 新增真实视频时，原始输入图继续独立显示和提供下载，不得被播放器替换或删除。
- 页面使用“输入图 → 输出视频”的并列对照，让观看者在视频播放前后都能理解生成关系。
- 视频封面必须从真实输出成片抽取，不得把输入图直接当作输出封面。
- 多参考图案例接入成片时，继续保留该案例的全部 Picture；窄屏可以改为素材带或纵向排列，但不能隐藏输入证据。

## 五套输入

| 案例 | 能力 | 图片 | 时长 | 画幅 | 声音重点 |
| --- | --- | ---: | ---: | --- | --- |
| CASE 001 | 三人物遮挡衔接连续镜头 | 3 | 15s | 16:9 | 连续画廊声场、空间脚步、布料掠过 |
| CASE 002 | 双人 3:1 差速舞蹈 | 1 | 12s | 16:9 | 脚步同样保持 3:1 感知比例 |
| CASE 003 | 同一人物三姿态微型飞行 | 3 | 15s | 9:16 | 气流和近身布料声跟随摄影机路径 |
| CASE 004 | 多参考帆板时尚 MV 入场段 | 3 | 15s | 9:16 | 风、帆、横杆、板和水声与画面接触同步 |
| CASE 005 | 水上闯关综艺喜剧 | 1 | 15s | 16:9 | 三句普通话、主持、观众与落水声不重叠 |

CASE 001 与 CASE 005 已返回外部真实成片并接入页面；CASE 002–004 仍等待外部结果。CASE 001 的通过项、偏差与提示词归因见 [`case-001/README.md`](case-001/README.md)；CASE 005 的 V1 因果失败与待验证 V2 见 [`case-005/README.md`](case-005/README.md)。

## 输出验收

- 图片职责没有串线，主体身份和服装稳定。
- 视频时长、画幅与案例卡片一致。
- MP4 确实包含音轨，而不是静音文件。
- 对白清楚且不重叠；动作声与可见接触同步；音乐不遮挡对白或关键物理声。
- CASE 001 无切镜；CASE 002 不回到同步；CASE 003 不变成幻灯片；CASE 004 装备连接可信；CASE 005 不只检查剧情节点顺序，还必须看见机关接触到身体入水的完整因果链。
