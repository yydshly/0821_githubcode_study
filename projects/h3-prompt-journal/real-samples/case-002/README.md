# CASE 002 · 双人 3:1 差速蝴蝶步

- 图片：`picture-1-duo-dancers.png`
- 参数：`MiniMax-H3 / Ref2VA / 12s / 768P / 16:9`
- 重点：左侧快者每完成三个动作，右侧慢者只完成一个；慢者先观察再模仿，不能追平或在结尾同步。
- 声音：分别可辨的脚步也呈现约 3:1 数量差，器乐节拍不能把两人重新拉回同拍。

Prompt 从网页样例卡片下载，与上方设计器恢复默认后的 CASE 002 完全一致。

### 测试失效

- **通过：**两人身份、橙色 / 蓝色服装、初始左右位置与排练室环境基本稳定，双声道音轨存在。
- **失败：**每 `0.5s` 抽样一次的 25 个画面全部没有显示完整双脚；约 `3.208s / 9.708s` 出现两次明显切镜；无法观察蝴蝶步，也无法计数 3:1 动作比例。
- **主要归因：**V1 同时要求“清晰全身动作”和“膝盖或腰部以上近距离环绕、避免远景”。更具体的摄影指令压过了动作可观察性；网页结构校验没有识别这组语义冲突。
