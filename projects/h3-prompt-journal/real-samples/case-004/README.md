### 参考职责审计

- **Picture 1 / 人物：**青橙运动服、体型和深色束发可辨；人物始终较远，不能把服装一致误写成脸部身份已经严谨验证。
- **Picture 2 / 装备：**橙色帆与青色板的整体色彩和轮廓保留，但横杆出现环状变形，桅杆、脚部和板面的连接关系不稳定。
- **Picture 3 / 摄影：**低水位、逆光、大浪和喷雾最稳定；没有明显把摄影图误当人物或装备参考。
- **音乐峰值：**半秒 RMS 包络在约 `10.0–11.5s` 明显上升，和 Prompt 的 `00:10` 主峰值基本一致；信号检测不能单独证明每一种风浪或器材声都准确同步。

结论不是“模板失败”，而是**参考职责分离在粗粒度上有效，细粒度运动学仍欠约束**。V1 只写了可信连接，没有明确双手必须抓住同一根连续横杆、桅杆脚固定在板面、非腾空时板底持续受水、脚不得穿模等逐帧不变量。下一轮应先锁定这些接触规则，再用重复样本区分 Prompt 改进和模型能力方差。
