### 结构通过、体验失败

- **通过：**同一张脸、发型、酒红外套、黑裤与短靴稳定；三个姿态按顺序出现；人物和摄影机都有连续变化。
- **失败：**前约 5 秒成为贴鞋、贴腿、贴手的人体扫描；微型尺度缺少可见通道、障碍和强视差；约 `10.4s` 后人物长期保持英雄姿态，仅剩一次贴脸推拉。
- **声音边界：**双声道存在且连续，但半秒左右声道 RMS 差不超过 `0.4 dB`、整段相关系数约 `0.987`，信号层面没有显示强烈的左右飞行扫动；这不能代替主观混音听审。

用户认为它“不如不套模板”是合理的。默认模板解决的是“三张姿态不要变成三页幻灯片”，不是保证动作短片更好看。三图本来就共享人物、服装和空间，身份风险较低；继续叠加厘米级贴近、频繁避让、三姿态逐项打卡和英雄收尾，使模型把摄影检查清单放在动作动机与审美节奏之前。

下一轮应先选目标：若优先追求成片效果，放弃完整模板，只把三图作为身份和动作灵感，写一个连续表演目标与三次镜头节拍；若专门测试微型飞行，则保留策略，但加入靴底缝隙、外套下摆、肘部窗口等可见尺度通道，并把任何姿态停留限制在 `0.4s` 内。
