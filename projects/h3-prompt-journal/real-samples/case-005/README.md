# CASE 005 · 水上闯关综艺喜剧 · V1 结果与 V2 修复

- 图片：`picture-1-contestant.png`
- 参数：`MiniMax-H3 / Ref2VA / 15s / 768P / 16:9`
- V1 重点：固定七个剧情节点顺序，但允许模型决定具体动作、机位、剪辑、表情和观众反应。
- 普通话对白：开场“大家好，我今天一定一次过关！”；摔倒时画外主持“稳住——还有机会！”；落水后“我只是下来降个温。”
- 声音：对白不得重叠；观众、机械、脚步、碰撞和落水声具有空间位置；对白出现时配乐自动降低。

V1 Prompt 从网页样例卡片下载，与上方设计器恢复默认后的 CASE 005 完全一致。

## 失败归因

V1 将 7 个节点和 3 句对白压入 15 秒，同时把具体动作、机位和剪辑节奏广泛放权。它只命名了“侧面机关反转”，没有定义机关空间、运动方式、接触点，也没有禁止用切镜隐藏原因。提示词与任务设计因此是主要贡献者，模型执行方差是次要边界。

## V2 修复 Prompt

- 英文生产版：`docs/demos/h3-prompt-journal/assets/case-005-real-test/prompt-v2.en.txt`
- 中文理解版：`docs/demos/h3-prompt-journal/assets/case-005-real-test/prompt-v2.zh.txt`
- 状态：**待外部 H3 验证，不是已证明成功的 Prompt。**

V2 将 7 个节点缩减为 5 段，只保留滚筒与高墙机关；固定高墙、摆臂和水池的空间关系；要求从机关启动、接触、失衡到身体入水使用同一条不中断侧面大全景；自由度只保留给细小步法、表情、观众反应和安全的喜剧表演。
